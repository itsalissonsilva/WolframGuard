# Disclosure status and private report template

No vulnerability has been demonstrated. No private or public vulnerability report has been sent. No CVSS score is assigned.

If a later trial reproducibly bypasses a documented default control, prepare a private report to Wolfram Research before publication. Verify the current official reporting channel at that time; do not guess a destination or send automatically.

The private report must include affected paclet/kernel/client versions; exact default setup and documentation; attacker-controlled input; unchanged legitimate request; required privileges and interaction; model and inference settings; tool/approval/kernel traces; independently captured before/after state; reproduction commands; synthetic impact; comparison against restricted tools; and remaining uncertainty.

Distinguish: expected evaluator capability; an agent's instruction-boundary failure; successful client interception; intentionally permissive client behavior; and a verified bypass of a specific default security control. Source inspection of Session evaluation alone is not proof of the last category.
